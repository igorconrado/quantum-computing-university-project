# Capítulo 9 - Quantum Algorithms

## Conteúdo do Capítulo

O capítulo 9 aborda os principais algoritmos quânticos:

- **Deutsch-Jozsa Algorithm** - Determina se uma função é constante ou balanceada
- **Bernstein-Vazirani Algorithm** - Encontra um string secreto
- **Simon's Algorithm** - Encontra período de funções
- **Grover's Algorithm** - Busca em banco de dados não estruturado (speedup quadrático)

## Exercícios para Implementar

### 1. `deutsch_jozsa.ipynb`
Implementar o algoritmo Deutsch-Jozsa para funções de 2, 3 e 4 qubits.

### 2. `grover_search.ipynb`
Implementar o algoritmo de Grover para busca em lista de 4 e 8 elementos.

### 3. `quantum_oracle.ipynb`
Criar oráculos customizados para os algoritmos acima.
